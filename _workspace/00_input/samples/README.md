# 샘플 사진 세트 (정확도 평가용)

목표: 먹기 전·후 사진 10쌍 이상. 1단계(10/29) 첫 측정에 최소 5쌍, 4단계(11/2~3) 개선 전까지 10쌍.
이 폴더의 사진은 평가용 로컬 파일이다. 앱이나 Firebase에 올리지 않는다.

## 찍는 법
- 위에서 내려다보는 각도. 먹기 전과 먹은 후를 같은 위치·각도에서 찍는다.
- 숟가락이나 젓가락을 함께 프레임에 넣는다(크기 단서).
- 다양하게 섞는다: 한 그릇 음식, 밥+국+반찬, 나눠 먹는 반찬, 국물 음식, 다 먹은 접시, 거의 안 먹은 접시, 양식·중식 등 한식이 아닌 음식.

## 파일 이름
`01_before.jpg`, `01_after.jpg`, `02_before.jpg`, `02_after.jpg` …

## 기대값 (`expected.json`)
가능하면 주방 저울로 그릇째 잰 뒤 빈 그릇 무게를 뺀다. 저울이 없으면 포장 표기나 눈대중으로 적고 `"measured": false`로 둔다.
칼로리는 적지 않아도 된다. 중량으로 코드가 계산한다.

```json
{
  "01": {
    "measured": true,
    "items": [
      { "name": "쌀밥", "before_g": 210, "after_g": 30, "eaters": 1 },
      { "name": "배추김치", "before_g": 60, "after_g": 20, "eaters": 2 }
    ],
    "note": "점심. 김치는 둘이 나눠 먹음"
  }
}
```
